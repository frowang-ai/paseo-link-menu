# Paseo Link Menu

[English](README.md) | 简体中文

右键 Paseo 聊天中的链接，复制实际网址或文件路径，或在系统文件管理器中定位本地文件。在 Windows 上，**在资源管理器中显示**会打开文件所在文件夹并选中文件，方便用常用软件打开视频、演示文稿、PDF 等。左键点击仍沿用 Paseo 原有行为。

## 安装

在工作区所属的 Paseo daemon 主机上安装：

```sh
paseo plugin add git:frowang-ai/paseo-link-menu
```

连接该主机的桌面、网页客户端会收到插件。运行 ID 为 `link-menu`，不需要 API key、后端进程或运行时 npm 依赖。

插件声明要求 Paseo **0.10.1 或更新版本**。文件定位另需桌面客户端提供文件管理器接口，已在 Windows / Paseo 0.16.2 上验证。没有该接口的旧桌面端仍可复制链接。macOS、Linux 会使用宿主提供的文件管理器入口，尚未进行对应系统实测。

## 使用

1. 右键聊天中的网页链接或文件链接。
2. 选择**复制链接地址**，复制原始链接目标；百分号编码会解码为可读字符。
3. 对当前桌面本机主机上的文件，选择**在资源管理器中显示**。其他系统对应 Finder 或系统文件管理器。

文件链接会打开所在文件夹并选中文件；以 `/` 结尾的目录链接会打开该目录。相对路径按当前工作区目录解析。支持 Windows 盘符路径、盘符前多一个斜杠的路径、本机 `file:` URL、空格、Unicode，以及常见行号和页码标记。文件不存在时会提示错误并允许重试。

远程主机文件不能在本机定位。不支持网络共享路径或 WSL 到 Windows 的路径转换。网页客户端仅提供复制，因为它不能直接控制系统文件管理器。

插件加载时会预先查询本机桌面身份并缓存成功结果，按操作系统选择内置文件管理器。每次右键不再枚举全部编辑器；启动准备未完成时，首次打开菜单可能短暂等待，查询失败会重试。每次打开菜单仍核对所属主机，执行定位时由 Paseo 检查文件是否存在。

连接的多个主机可以各自提供此插件。0.2.2 及之后版本在同一页面共享一个菜单和右键监听，卸载其中一份不会影响其他安装。若旧版同时加载，新监听会先处理右键事件，避免出现两个菜单；不会卸载任何主机上的插件。

点击菜单外部或按 Escape 关闭菜单。对已选中文字右键时保留宿主的选区操作。菜单跟随聊天主题，无法识别时使用系统主题；中英文标签跟随浏览器语言。

## 平台与数据访问

菜单适用于桌面、网页客户端，原生 iOS / Android 不提供此菜单。

插件读取所点链接，仅在选择复制时写入剪贴板。定位文件前会检查本机桌面身份，必要时通过现有 Paseo 连接读取工作区目录，再调用桌面文件管理器接口。没有后端，不向外部服务发送链接内容，也不保存链接内容。

Paseo 尚无公开的链接右键菜单或本地文件定位插件 API。当前实现依赖聊天 DOM（`agent-chat-scroll` 与链接元素）、工作区路由和桌面 preload bridge。文件管理器适配集中在 `client/reveal.ts`，DOM 操作集中在 `client/web.ts`。无法确认的上下文不会切换到其他主机尝试；宿主接口或页面结构变化后可能需要更新插件。

## 开发

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
paseo plugin install /absolute/path/to/paseo-link-menu
```

修改源码后：

```sh
npm run typecheck
paseo plugin reload link-menu
```

## 验证范围

- 类型检查与 12 组测试覆盖路径解析、本地工作区解析、远程主机拒绝、文件管理器选择、启动与并发查询复用、缓存隔离及身份查询失败后的重试。
- 在隔离的 Paseo 0.16.2 Windows 桌面窗口中，通过真实菜单和原生接口打开资源管理器，选中含中文及空格的示例文件，并通过 Windows Shell 读回选中路径。
- 同一桌面探针检查了文件不存在、远程主机不可用、相对路径与行号链接、网页链接复制，以及明暗主题。相对路径使用示例工作区适配器，文件打开接口为真实接口。
- 提速后，5 次预热菜单测量从右键事件到定位按钮可用耗时 11–27 ms；该次启动身份准备约 1.6 秒。这不是资源管理器启动耗时保证。
- 在同一隔离桌面中复现了旧版、新版同时显示两个菜单；重载 0.2.2 后只显示一个，定位按钮可用。浏览器生命周期探针覆盖独立 bundle、重复安装、两种卸载顺序、重复清理和新旧版加载顺序，复制与定位各触发一次。
- 未实测原生 iOS / Android 菜单和 macOS / Linux 文件管理器。本文预览图仅用于展示中英文菜单，不扩大上述验收范围。
