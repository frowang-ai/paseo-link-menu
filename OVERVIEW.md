Link Menu adds right-click actions to links and file paths inside Paseo chats. Copy link address copies the underlying target with percent-escaped characters decoded. In Paseo Desktop, Show in Explorer (or the system file manager) opens a local file's containing folder and selects it, so you can use your normal video, presentation, or PDF application. Ordinary left-click behavior is unchanged.

The menu follows the surrounding theme and uses Chinese or English labels. Copy works in desktop and browser clients; file reveal requires the desktop file-manager bridge and a chat on that desktop's local host. Relative paths resolve against the current workspace. Directory links ending in a slash open the directory, and file links can include common line or page markers. Missing files show an error with a retry action. Remote-host files, network shares, and WSL-to-Windows path conversion are not supported. Native iOS and Android do not provide this menu.

When several connected hosts supply the plugin, current versions share one menu per app page. An older copy can remain installed on another host without covering the current menu.

There is no backend, API key, or runtime dependency setup. The plugin reads the clicked link, checks the local desktop host, and reads the workspace directory through the existing Paseo connection when needed. Copy writes to the clipboard; file reveal uses Paseo Desktop's existing file-manager bridge. It sends no link contents to external services and does not save them.

The existing copy menu requires Paseo 0.10.1 or later. File reveal has been verified on Windows with Paseo 0.16.2; macOS and Linux have not been exercised. The menu depends on Paseo's chat DOM, workspace route, and desktop preload bridge because these actions have no public plugin API. Future host changes may require an update.
